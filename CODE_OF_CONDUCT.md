# Code of conduct

docx-to-pdf follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md) in
its repository, its issues, pull requests and discussions, and wherever someone speaks for the project.

## Reporting

If someone's behaviour breaks the code of conduct, report it privately to the maintainers by email, at
<kustov.vitalik@gmail.com>. Say what happened, where and when, with links if there are any. The maintainers keep the
report confidential, answer you, and decide what to do as the code of conduct sets out. A maintainer a report
concerns takes no part in deciding it.

The project has one maintainer today, so a report about that maintainer has nobody else in the project to decide it.
Who decides such a report will be settled when the project has more maintainers.
