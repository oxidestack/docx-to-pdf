# docx-to-pdf

An HTTP service that converts DOCX, DOC, ODT and RTF documents to PDF with LibreOffice.

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 0.1.0](https://img.shields.io/badge/AppVersion-0.1.0-informational?style=flat-square)

This README is generated by [helm-docs](https://github.com/norwoodj/helm-docs) from `README.md.gotmpl` and the
`# --` comments in `values.yaml`: edit those and run `make chart-docs` (the `chart-docs` gate fails on a stale copy).

## Installing

```console
helm install docx-to-pdf oci://quay.io/oxidestack/charts/docx-to-pdf --namespace docx-to-pdf --create-namespace
```

The memory limit is computed from `poolSize` and `instanceHardMemoryMiB` (and a tmpfs, if any), so the pod cannot be
OOM-killed while a conversion is within its limit: `docs/guide/operations.md`, "Sizing", in the repository.
`values.schema.json` refuses a misspelt or mistyped value.

A NetworkPolicy, on by default (`networkPolicy.enabled`), admits the pods' ingress on port 8080 only and their egress to
DNS and the port of `otel.endpoint` only: a conversion opens no connection. It takes effect where the cluster's network
plugin enforces NetworkPolicy.

## Requirements
